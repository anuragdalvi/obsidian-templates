# Obsidian Starter Vault Template

A portable, opinionated Obsidian vault seed using **PARA** + **LYT Maps of Content**.  
Open this folder in Obsidian → plugins and theme load automatically.

## Folder structure

| Path | Purpose |
|------|---------|
| `00_Inbox/` | Unprocessed notes; daily & weekly periodic notes |
| `01_Projects/` | Finite work with a clear deliverable |
| `02_Areas/` | Ongoing responsibilities (no end date) |
| `03_Resources/` | Reference material, playbooks, research |
| `04_Archive/` | Completed / inactive items |
| `05_MOCs/` | Maps of Content — topic entry points |
| `90_Meta/Templates/` | Templater templates (do not delete) |
| `90_Personal/` | Private notes — not committed to git |

## Plugins installed

| Plugin | Purpose |
|--------|---------|
| Dataview | Live queries across the vault |
| Templater | Template engine with folder defaults |
| Periodic Notes | Daily + weekly notes |
| Tasks | Task tracking with due dates |
| Obsidian Linter | Auto-format + YAML timestamp on save |
| Omnisearch | Full-text search |
| Obsidian Git | Auto-backup to git |
| Advanced URI | Deep-link to notes |
| URL Into Selection | Paste URL over selected text |
| Excalidraw | Whiteboard diagrams |
| Mermaid Tools | Mermaid diagram helpers |

## Quick start

1. `Obsidian → Open folder as vault` → point to this directory
2. Trust community plugins when prompted
3. `Ctrl/Cmd+P` → *Periodic Notes: Open today's daily note* — first note!
4. Open `Home.md` as your dashboard

## Known issues

_None at build time. If a plugin fails to load, re-install from the community store:_  
`Settings → Community plugins → Browse → search by name`
